# Waleed Haroon - Portfolio

A modern, responsive portfolio website showcasing my work as a Web Developer, built with vanilla HTML, CSS, and JavaScript.

## 🌟 Features

- **Responsive Design**: Mobile-first approach that works seamlessly on all devices
- **Modern UI**: Clean, professional design with a purple color theme
- **Smooth Animations**: Subtle transitions and hover effects for enhanced user experience
- **Interactive Elements**: Mobile navigation toggle, smooth scrolling, and dynamic content
- **Accessibility**: Semantic HTML, ARIA labels, and keyboard navigation support
- **SEO Optimized**: Meta tags and Open Graph tags for better search engine visibility

## 🎨 Design Theme

The portfolio uses a modern purple color palette:
- **Primary**: #8B5CF6

## 📋 Sections

- **Hero**: Introduction with name, role, and call-to-action buttons
- **About**: Background blending web development, photography, media handling, and sports
- **Skills**: Showcase of technical skills including HTML, CSS, JavaScript, React, Python, and WordPress

## 🚀 Local Development

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A code editor (VS Code recommended)
- VS Code Live Server extension (optional but recommended)

### Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/WaLeedHaRooN786/Portfolio.git
   cd Portfolio
   ```

2. **Open with VS Code**:
   ```bash
   code .
   ```

3. **Run with Live Server**:
   - Install the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code
   - Right-click on `index.html`
   - Select "Open with Live Server"
   - The portfolio will open in your browser at `http://localhost:5500`

4. **Alternative**: Open directly in browser:
   - Simply double-click `index.html` to open it in your default browser
   - Or drag and drop `index.html` into your browser window

## 🌐 GitHub Pages Deployment

To deploy this portfolio to GitHub Pages:

1. **Go to your repository on GitHub**
2. **Navigate to Settings** → **Pages** (in the left sidebar)
3. **Under "Build and deployment"**:
   - Source: Select **"Deploy from a branch"**
   - Branch: Select **`main`** (or your default branch)
   - Folder: Select **`/ (root)`**
4. **Click Save**
5. **Wait a few minutes** for GitHub to build and deploy your site
6. **Your portfolio will be live** at: `https://waleedharoon786.github.io/Portfolio/`

### Custom Domain (Optional)

To use a custom domain:
1. Add a `CNAME` file to the root directory with your domain name
2. Configure your domain's DNS settings to point to GitHub Pages
3. Enable "Enforce HTTPS" in the Pages settings
